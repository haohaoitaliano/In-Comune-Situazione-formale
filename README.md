# In Comune – Situazione formale

Esercizio interattivo di italiano A2 sulle espressioni formali e il pronome di
cortesia **Lei** in una conversazione al Comune.

## Anteprima locale

Apri `index.html` direttamente nel browser oppure, dalla cartella del progetto,
avvia un semplice server locale:

```sh
python3 -m http.server 8000
```

Poi visita `http://localhost:8000`.

Il progetto usa solo HTML, CSS e JavaScript e può essere pubblicato direttamente
con GitHub Pages.
